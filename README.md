# SimpleCardGame v2

4 人阵营扑克牌游戏（重构版）。后端 C++17，前端原生 Web（开发中）。

## 玩法

- 4 人局，52 张牌每人 13 张
- **阵营**：红桃2（♥2）与黑桃K（♠K）的持有者组成"关键队"，另两人为"平民队"；若同一人同时持有 ♥2 和 ♠K，则该人**独自一队**（1v3）
- **胜利**：同队所有成员都出完手牌 → 该队获胜
- **牌型**：单张、对子、三条、三带二、顺子（≥5 张、2 不入顺、A 仅作高端）、炸弹（四条）、四带两单、四带两对
- 炸弹可压任意牌型，炸弹间比点数；**允许炸队友**
- 首出者：♣3 持有者（首手不限牌型）
- 回合制：领出者不可 PASS；PASS 后本轮锁定；3 人 PASS（未出完人数−1）后最后出牌者领出新轮
